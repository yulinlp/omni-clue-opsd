## xysui gpu04 并行 OPSD

最初的 torchvision/PyAV 版本在 xysui 的 Slurm 作业 `279142`（gpu04）上于第一个优化步前失败，原始日志和目录保留在：

```text

```

安装 decord2 后，4 卡、真实视频+音频、`max_steps=1` 的冒烟测试通过，耗时约 61.8 秒并生成 `checkpoint-1`。冒烟目录为：

```text
output/xysui_opsd_smoke_decord2_20260908_0219/
```

随后按同一 `su - xysui`、`ssh gpu04`、`su - ylhu` 路径启动了修复后的正式 OPSD：

```text
output/xysui_opsd_formal_decord2_20260908_0222/opsd/
CUDA_VISIBLE_DEVICES=0,1,2,3
OMNI_OPSD_NPROC_PER_NODE=4
OMNI_OPSD_MAX_STEPS=300
OMNI_OPSD_GRADIENT_ACCUMULATION_STEPS=16
FORCE_QWENVL_VIDEO_READER=decord
```

gpu04 修复后正式任务的外层 PID 和四个 worker 会写入该目录的 `runner.pid` 和 `opsd.log`。训练进程使用 `nohup setsid`，SSH/Codex 断开不会主动终止它；但 Slurm 作业结束或被取消时进程仍会退出。外层 shell 的后台 job 显示完成不代表训练结束；应以分布式 worker、GPU 显存和日志进度为准。

正式任务的预计耗时按冒烟测试约 61.8 秒/优化步、梯度累积 16 估算为约 82 小时，超过作业 `279142` 当前的时间上限（2026-09-10 22:54）。因此需要在首个正式优化步完成后用日志中的实际 `train_speed(s/it)` 重新评估；若保持当前有效 batch=64，当前作业窗口可能不足以完成 300 步。
